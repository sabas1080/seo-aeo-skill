## Ideas clave

1. Revisar a mano cada chatbot no escala, un scraper propio por plataforma se rompe con cada cambio y las herramientas
   cerradas de monitoreo son caras y rígidas: los datos estructurados por API se conectan a tableros e informes.
2. **Tres tipos de dato según la pregunta**: la respuesta real de una keyword en AI Overviews o **AI Mode** (¿se dispara?,
   ¿nos cita?, ¿qué competidores salen?, ¿AI Mode usa las mismas fuentes que el Overview?); la respuesta de ChatGPT o
   Gemini a un prompt (texto, fuentes citadas, marcas mencionadas, guardada para comparar en el tiempo); y una base
   agregada de muchas respuestas para ver frecuencia de cita, tendencias, dominios y páginas más mencionadas.
3. Referencia de costo que dan: más de 800 respuestas de IA por menos de un dólar.
